# Формат палитр (Color Palette / Index-Remapping Format)

Ресурс `palettesAmount.bin` хранит вспомогательные таблицы переназначения индексов цветов (Index-Remapping or Palette Swapping tables), используемые графическим движком игры для динамического реколоринга (изменения цвета одежды врагов, эффектов ранений, подсвечивания предметов и т.д.).

---

## 1. Спецификация структуры
Файл имеет простой бинарный формат без сжатия:

| Смещение | Размер (Байт) | Тип | Назначение |
| :--- | :--- | :--- | :--- |
| `0x00` | 1 | Byte | Общее количество палитр (`N = 31`) |
| `0x01` | 1 | Byte | Длина первой палитры (`L_0 = 20`) |
| `0x02` | `L_0` | Bytes | Данные индексов ремаппинга первой палитры |
| `0x16` | 1 | Byte | Длина второй палитры (`L_1 = 3`) |
| `0x17` | `L_1` | Bytes | Данные второй палитры |
| ... | ... | ... | ... |

---

## 2. Локализованные палитры
Всего извлечено **31 палитра** (сохранено в `research/resources/palettes/` в формате JSON):

*   **Количество палитр:** 31
*   **Диапазон размеров:** от 2 до 32 байт.
*   **Формат значений:** Индексы без знака (`uint8`), представляющие собой целевые смещения в палитре цветов основного текстурного атласа `t0`.
*   **Порядок байтов (Endianness):** Big-Endian / байт-ориентированный (нет многобайтовых целых чисел).

---

## 3. Связь с графическим движком (`t0`) и кодом
*   **Загрузка в коде:** Палитры считываются методом `g.S()` при старте игры. Данные записываются в глобальный двумерный байтовый массив `g.a` (имеет тип `byte[][]`).
*   **Использование (Ремаппинг):** При отрисовке кадров спрайтов через класс `a` (метод `a.a(id, frame, x, y, palette_index)`), если параметр `palette_index` больше нуля, графический движок подменяет оригинальные индексы цвета пикселей на соответствующие значения из массива `g.a[palette_index]`.
*   **Зачем это нужно:**
    *   **Разнообразие зомби:** Позволяет использовать один и тот же спрайт зомби, но красить их одежду в разные цвета (зеленый, красный, синий) без дублирования текстур в JAR.
    *   **Эффект ранения:** Кратковременный красный фильтр на спрайте игрока или врага при получении урона.
    *   **Подсветка элементов UI:** Мерцание кнопок или элементов меню.
