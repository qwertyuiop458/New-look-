# Связь бинарных ресурсов с Java-кодом (Resource-Java Links Map)

В данном документе приведено точное сопоставление игровых бинарных ресурсов с загрузчиками, структурами хранения и методами потребления в Java-коде оригинальной игры.

---

## 1. Сводная таблица связей ресурсов

| Ресурс | Класс-загрузчик | Метод загрузки | Переменная назначения | Классы-потребители | Назначение ресурса |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **`t0`** | `g` | `g.a(...)` | `g.a[0]` (тип `a`) | `g`, `f`, `c` | Основной графический пак (атласы спрайтов персонажей, оружия, анимаций и UI). |
| **`palettesAmount.bin`** | `g` | `g.S()` | `g.a` (тип `byte[][]`) | `a` | Таблицы динамического ремаппинга цветов спрайтов (реколоринг зомби, эффект ранения). |
| **`dataIGP`** | `b` | `b.a(...)` | `b.a` (тип `byte[]`) | `b` | Текстовые строки и конфигурация рекламного/онлайн портала Gameloft IGP. |
| **`m0` — `m13_2`** | `g` | `g.a(byte[])` | `g.a` (тип `byte[]`) | `g`, `f` | Бинарные пакеты уровней (разметка сетки проходимости тайлов, триггеры, ИИ-спаунеры, тексты диалогов). |

---

## 2. Детальное описание потоков данных

### `t0` (Основная графика)
*   **Логика загрузки:**
    *   При запуске игры или инициализации графики движок считывает `t0` из JAR.
    *   Данные передаются в метод `a.a(byte[], int)`, который парсит бинарные смещения, размеры и загружает изображения в двумерный массив `Image[][] a` класса `a` (срезая тайлсеты в рантайме).
*   **Использование:** Метод `c.a(Graphics)` извлекает нужный кадр из объекта `a[0]` и выводит его на Canvas с помощью графического контекста J2ME.

### `palettesAmount.bin` (Таблицы замены цветов)
*   **Логика загрузки:**
    *   Считывается методом `g.S()` при старте игры.
    *   Сначала считывается первый байт (число палитр `N`), затем в цикле извлекается длина каждой палитры и сами байты ремаппинга. Записывается в `g.a`.
*   **Использование:** При вызове отрисовки `a.a(..., palette_index)` байты подменяются в соответствии с таблицей `g.a[palette_index]` перед выводом кадра.

### `dataIGP` (Интеграция IGP-портала)
*   **Логика загрузки:**
    *   Загружается классом `b` через стандартный `.getResourceAsStream("/dataIGP")`.
*   **Использование:** Текстовые данные декодируются в кодировке UTF-8 или Win-1251 для отображения пунктов портала Gameloft Live, ссылок для покупки полной версии игры или отправки рекордов.

### `m0` — `m13_2` (Карты уровней)
*   **Логика загрузки:**
    *   При инициализации уровня (стейт `2`, метод `g.F()`), загружается соответствующий бинарный файл (например, `/m3_0`).
    *   Байты передаются в метод инициализации карты `g.a(byte[] var0)`.
*   **Использование:** 
    *   Метод `g.a` нарезает байты на слои карты. Сетка проходимости забивается в 3D массив `g.g` для расчёта коллизий игрока и зомби.
    *   Текстовые блоки диалогов считываются и парсятся интерпретатором квестов (класс `g`).
    *   Координаты спауна зомби считываются и передаются в пул объектов менеджера сущностей `f`.
