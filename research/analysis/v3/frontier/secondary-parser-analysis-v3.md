# Secondary Parser Analysis V3

**g.a(byte[]) (g.java:1682-1870)** — парсер ТАБЛИЦ СЦЕН (не mission opcode!).

- Вход: g.a[0] = число записей g.k; g.b[] = длины; g.c[] = смещения.
- Опкоды: 11,12,13,21,22,23,24,31,32,34,35,36,37,38,39,41,42,43,44 (19 значений).
- Заголовки: 2 = переход (ссылка на другую запись), 3 = спавн сущности.
- Опкод 37 = палитра-ремаппинг (чтение u16, подстановка).
- Назначение: таблицы сценариев, исполняемые g.g() при загрузке (state 2).
- Отличие от mission opcode: mission = g.z/H()/K() (110-172); secondary = g.g() сцены.

Статус: структура CONFIRMED; семантика 19 опкодов — REQUIRES_REAL_RUNTIME (данные в статических таблицах).
