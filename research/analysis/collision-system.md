# Система коллизий и столкновений (Collision & Physical System)

В данном документе приведено детальное описание математики, сетки проходимости и механизмов расчёта физических столкновений в игре **Zombie Infection**.

---

## 1. Математика системы координат (Fixed-Point Grid Math)
Для расчёта физики игра использует систему с фиксированной запятой (Fixed-Point Math, дробная часть `14` бит, коэффициент сдвига `16384`):
*   **Игровая координата (Fixed-Point):** `X_fixed` / `Y_fixed`.
*   **Координата в пикселях экрана:** `X_pixel = X_fixed >> 14`.
*   **Координата в тайлах карты:** `X_tile = X_pixel >> 4` (так как один тайл имеет размер `16x16` пикселей, что равно `2^4`).
*   **Суммарная формула перехода к тайлу:** `X_tile = X_fixed >> 18`.

Эта математика используется при проверке коллизий игрока и врагов во время движения в классе `f.java`:
- Метод проверяет будущее положение игрока: `future_x = X_fixed + speed_x`.
- Извлекается ячейка карты: `tile_x = future_x >> 18`, `tile_y = future_y >> 18`.
- Запрашивается проходимость тайла: `grid_value = g.g[current_layer][tile_x][tile_y]`.

---

## 2. Физическая сетка проходимости (Tile Collision Masks)
Каждый тайл в сегменте `1` файла уровня кодирует проходимость с помощью битовой маски:

*   **`Walkable` (Проходимо):** Значение `0` (или отсутствие бита блокировки). Игрок и зомби могут свободно ходить.
*   **`Solid Wall` (Сплошная преграда):** Значение `1` (или выставленный бит блокировки). Любое движение сквозь ячейку блокируется.
*   **`Door` (Дверь):** Ячейка проходима только в том случае, если связанный с ней триггер двери в `g.java` находится в состоянии "ОТКРЫТО".
*   **`Ladders / Stairs` (Лестницы):** Позволяют вертикальное перемещение между слоями карты (переключение `layer` в массиве `g.g`).

---

## 3. Коллизии объектов (AABB AABB Collisions)
Столкновения между активными сущностями (например, пуля-зомби или зомби-игрок) рассчитываются по классическому методу **AABB (Axis-Aligned Bounding Box)** на плоскости в методах класса `f.java`:
```java
// Упрощенный кодовый аналог проверки коллизии двух сущностей
boolean checkCollision(c actor1, c actor2) {
    int x1 = actor1.a() - (actor1.width >> 1);
    int y1 = actor1.b() - actor1.height;
    int x2 = actor2.a() - (actor2.width >> 1);
    int y2 = actor2.b() - actor2.height;
    
    return (x1 < x2 + actor2.width &&
            x1 + actor1.width > x2 &&
            y1 < y2 + actor2.height &&
            y1 + actor1.height > y2);
}
```
Если возвращается `true`, вызывается обработчик коллизии: пуля уничтожается и наносит урон, а при коллизии зомби-игрок у игрока отнимается здоровье и запускается анимация укуса.
