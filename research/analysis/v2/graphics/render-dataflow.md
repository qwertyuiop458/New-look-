## 1. Обратная цепочка (render call → raw binary)

```
drawImage / drawRegion (a.java:770/772)
  ← Image (кэш this.a[i][n]) или Image.createRGBImage (a.java:763)
  ← int[] пиксели (a.java:360: nArray2 = this.a(n))
  ← ДЕКОДЕР this.a(n) (a.java:800-960):
       this.j (byte[] RLE-блоки) + this.a[this.i] (int[256] палитра-индексы)
       форматы: 25840 (RLE+маска j), 10225 (RLE: 0x80+len повтор), 22258 (RLE-v),
                5632 (4bpp), 2048 (3bpp), 1024 (2bpp), 512 (1bpp), 22018 (8bpp)
  ← размеры кадра: this.c[n] & 0xFF (w), this.d[n] & 0xFF (h)
  ← объекты листа (k=0/1/2) из заголовка a.java-листа
  ← сырые байты сегмента (m0/m1/m2/m6_*/m7/m11_0/m11_1...)
```
