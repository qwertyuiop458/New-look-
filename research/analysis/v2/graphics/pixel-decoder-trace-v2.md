## 2. Цепочка преобразования

```
raw byte stream (сегмент спрайт-листа)
  → парсер a(byte[], int): объекты, палитры, блоки j
  → декодер a(int n): j[offset..] + палитра a[i][256] → int[] ARGB (буфер b, 16384)
  → Image.createRGBImage(pixels, w, h, alpha)     (a.java:763)
  → drawImage / drawRegion                        (a.java:770/772)
```

- **byte order:** LE (u16/u32 через байтовые сдвиги)
- **alpha:** флаг this.a (true если найден прозрачный пиксель; у 565: значение 0xF81F)
- **размеры:** w = c[n] & 0xFF, h = d[n] & 0xFF (из объектных записей)
