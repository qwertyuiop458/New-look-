## 2. c.java контроллер (подтверждено)

- `b(int n)`: установка анимации d=n, кадр e=0, повторы g=-1, loop h=1
- `a(int n, int n2, int n3)`: d=n, h=n2 (loop/once), повторы n3
- аккумулятор тиков: `j += n; while (j >= 62) { j -= 62; ... }` — кадр продвигается каждые 62 тика
- `a()`: loop: кадр = (кадр+1) % кол-во; once: до конца; повторы: --g
- `a(Graphics)`: рисует кадр: a.a(d, e, x, y, palette) — с учётом родительских смещений (a/b-цепочки)
