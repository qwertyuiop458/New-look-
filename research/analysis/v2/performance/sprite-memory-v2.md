# Sprite Memory V2

- Парсинг: a.java a(byte[],int): объекты (u16), палитры, b/f/e-записи -> внутренние массивы.
- Мини-кадры: a[8][h] int[][] (до 8 x 256 px) — декодируются при первом рендере (lazy: a(n) при обращении).
- Большие кадры: RLE-блоки j (byte[]) + палитра a[i][256] -> int[] буфер b (16384) — ОДИН общий буфер (reuse).
- Image кэш: a[i][n] (Image) — создаётся createRGBImage, кэшируется; флаг d[i] (2=Image, 4=int[]).
- Release: null при выгрузке (g.a[] = null); System.gc().
- Режимы: (g.ag): 1=scale, 2=alpha, 4=эффекты, 0x80=прямой.
- Lazy decode: мини-кадры декодируются при первом обращении (a(n)); Image кэшируется.
