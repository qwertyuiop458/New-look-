# Fixed-Point Performance V2

- Представление: int, 14 бит дробная (1 << 14 = 16384).
- Преобразования: << 14 (в фикс), >> 14 (в px), >> 4 или /16 (в тайлы).
- Умножения: n * 1000 / 819200 (скорости), x * 30 / 100 (проценты) — целочисленные.
- Деления: / n13 с защитой (n14 > 131071 ? n14/n13 << 14 : (n14 << 14)/n13) — переполнение-безопасно.
- Ускорение: 19660 * n9 / 70 (движение) — константы целые.
- Причины: CLDC-1.0 без float; сдвиги быстрее умножений.
