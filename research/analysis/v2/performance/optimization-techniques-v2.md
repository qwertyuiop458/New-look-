# J2ME Optimization Techniques V2 (по evidence)

1. Fixed-point (14 бит) вместо float.
2. Byte-array упаковка записей (u16 LE, бит-пак 1-8 bpp).
3. RLE-сжатие кадров + палитра-индексы.
4. Общий пиксельный буфер (16384 ints) — reuse.
5. Lazy декод + Image кэш.
6. Прелоад + кэш Player (2 канала).
7. Memory guards (freeMemory < 100000 -> пропуск звука).
8. Динамические буферы строк с System.gc().
9. Ограниченный счётчик сущностей (переиспользование слотов).
10. Data-driven ресурсы (таблицы вместо кода).
11. yield-спин вместо sleep (нет аллокаций).
12. Delta clamp 166 мс (защита от лагов).
