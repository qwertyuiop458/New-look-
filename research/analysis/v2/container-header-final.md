# Container Header — ФИНАЛЬНАЯ спецификация (из первичного кода)

**Дата:** 2026-08-14 · **Источник:** `research/decompiled/g.java`, метод `a(String)` (строки 4055-4075) и `b(int)` (строки 4077-4100).

## 1. Точное чтение header (цитата кода)

```java
A = a.read();                    // (1) count  — 1 байт, беззнаковый (int 0..255)
h = new int[A];
while (n < A) {
    h[n]  = a.read() & 0xFF;              // байт 0 (младший)
    h[n] |= (a.read() & 0xFF) << 8;       // байт 1
    h[n] |= (a.read() & 0xFF) << 16;      // байт 2
    h[n] |= (a.read() & 0xFF) << 24;      // байт 3 (старший) — uint32 LE
}
```

## 3. Доказательства (из кода)

- `b(int)`: `if (n < 0 || n >= A - 1) return null;` — последний сегмент **недоступен**; всего читаемых сегментов `A−1`.
- `int n2 = h[n+1] - h[n];` — размер сегмента n = разность соседних смещений.
- `int n3 = h[n] - h[B]; if (n3 > 0) a.skip(n3);` — от текущей позиции потока (после сегмента B) пропускается разность смещений; значит `h[]` — смещения от начала данных (base), а не от начала файла, и чтение идёт последовательно по возрастанию n.
- `byArray = new byte[n2]; a.read(byArray);` — сегмент читается целиком.
- `B = n + 1;` — позиция последнего прочитанного сегмента.
