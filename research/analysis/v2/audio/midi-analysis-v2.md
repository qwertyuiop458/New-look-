# MIDI Analysis V2

- Ресурс: m13_2 (медиа-контейнер).
- **14 MIDI-треков** (format 0, 1 трек, division 480), BPM: [80, 90, 100, 120, 130, 135, 140, 150, 163, 179].
- **15 RIFF/WAV** (сегменты 3-11, 13, 20-24, 29) — звуковые эффекты.
- Loop: setLoopCount(j[n]) (не в файле); громкость VolumeControl 100.
- Linkage MIDI->событие: REQUIRES_REAL_RUNTIME (нет таблицы music ID).
