## 2. Координатная цепочка (подтверждена)

```
fixed (14 бит) -->>14--> pixel (px) -->> /16 --> tile (индекс)
коллизии сущностей: AABB + 5-точечный зонд в пиксельных координатах
тайловые проверки: g.e(n/16, n2/16) (f.java:4979, 2388)
```
Операция `>> 18` в коде отсутствует (математический эквивалент) — см. formula-audit.

## 3. Чего НЕТ в level package

- битовой маски «solid/walkable» на весь уровень (как в старом анализе «m0 seg1 = collision 997 Б» — не подтверждается);
- тайловой сетки коллизий 64×64 (уровень не тайловый в этом смысле);
- «compact collision representation» из старого level-format.md для m3_0 — m3_0 это спрайты.

## 4. Требует рантайма

- точная семантика `g.b[10][10][8]` (сектора?);
- взаимодействие флагов проходимости (101) с объектами (22/23);
- пороги/реакции коллизий (скольжение, углы) — f.a(n,n2,n3,n4) поведение.
