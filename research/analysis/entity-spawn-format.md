# Формат спауна сущностей (Entity Spawn Format)

В данном документе приведено описание структуры размещения, спауна и инициализации игровых объектов на картах уровней игры **Zombie Infection**.

---

## 1. Спецификация формата спауна (Spawn Block)
Точки спауна считываются методом `f.a(byte[] var0, int var1)` из сегмента `2` пакета уровня при инициализации карты:

| Смещение в блоке | Размер (Байт) | Тип | Назначение |
| :--- | :--- | :--- | :--- |
| `0x00` | 2 | uint16 | Координата X спауна персонажа (переводится в fixed-point `<< 14`) |
| `0x02` | 2 | uint16 | Координата Y спауна персонажа (переводится в fixed-point `<< 14`) |
| `0x04` | 1 | Byte | Тип сущности (`entity_type`) |
| `0x05` | 1 | Byte | Начальная анимация / состояние сущности (`initial_state`) |
| `0x06` | 1 | Byte | Сложность / здоровье сущности (`health_index`) |

Все числовые значения координат `X` и `Y` записаны в формате **Little-Endian**.

---

## 2. Идентификация типов сущностей (`entity_type`)
При считывании типа сущности (`entity_type`) менеджер `f` инстанцирует соответствующего актера:

*   **`0`:** Главный герой (Player Character).
*   **`1`:** Рядовой Зомби (Common Zombie - Walker).
*   **`2`:** Быстрый Зомби (Runner Zombie).
*   **`3`:** Плюющийся Зомби (Spitter Zombie).
*   **`4`:** Зомби-Босс (Boss Zombie / Tank).
*   **`10`:** Аптечка (Health Pack) - интерактивный предмет.
*   **`11`:** Патроны (Ammo Pickup).
*   **`12`:** Сюжетный предмет / Ключ (Key Card / Story Item).

---

## 3. Кодовый поток данных (Code Flow)
1.  **Инициализация уровня:** При вызове `g.F()` из пакета уровня извлекается байтовый массив сегмента `2` (спаунеры).
2.  **Запуск парсера:** Метод `f.a(byte[] var0, int var1)` циклически проходит по массиву спаунеров.
3.  **Выделение памяти:** Для каждого врага создается объект `c` (Animation Component), инициализируются его координаты и подгружается соответствующий спрайт-лист (например, `segment_05.bin` для зомби).
4.  **Регистрация в пуле:** Объект регистрируется в массиве `f.a[]` (пул активных сущностей), откуда ежекадрово обновляется и отрисовывается.
