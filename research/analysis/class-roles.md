# Роли классов (Class Roles)

В следующей таблице приведено функциональное назначение всех 8 обфусцированных классов оригинальной игры:

| Класс | Предполагаемая роль | Уверенность | Доказательства и обоснование |
| :--- | :--- | :---: | :--- |
| **`GloftMASS`** | Главный класс приложения (MIDlet Lifecycle) | **HIGH** | Наследует `javax.microedition.midlet.MIDlet`. Содержит методы `startApp()`, `pauseApp()`, `destroyApp()`. Инициализирует главный поток игры через инстанс класса `g`. |
| **`a`** | Загрузчик, декодер и отрисовщик листов спрайтов (Sprite Sheet Engine) | **HIGH** | Содержит методы парсинга бинарных массивов в структурированные массивы изображений (`Image[][] a`, `int[][][] a`). Отвечает за вырезание и трансформацию (зеркалирование, поворот) кадров из листов спрайтов для их отрисовки через `Graphics`. |
| **`b`** | IGP (In-Game Portal) SDK от Gameloft и менеджер профилей сохранений | **HIGH** | Содержит строковую сигнатуру `"IGP-Signature="` и жесткие привязки к Gameloft Live Portal. Реализует отправку рекордов, покупку игр, а также обёртку для работы с RMS (`RecordStore`) для хранения игрового прогресса. |
| **`c`** | Анимационный контроллер спрайта / сущности (Animation Component) | **HIGH** | Оперирует фиксированной запятой (`<< 14` и `>> 14`) для плавного перемещения на устройствах без поддержки float. Хранит координаты `x`, `y`, ID анимации `d`, текущий кадр `e`, шаг анимации `h`. Отрисовывает себя через вызов методов класса `a`. |
| **`d`** | Глобальные конфигурационные флаги компиляции (Build Config Constants) | **HIGH** | Содержит только статические переменные типа `boolean` и `int` без единого метода. Переключает такие параметры как: поддержка вибрации, звука, сенсоров, чит-кодов, языка или отладки. |
| **`e`** | Контроллер датчиков движения (Accelerometer / Tilt Controller) | **HIGH** | Реализует интерфейс `javax.microedition.sensor.DataListener`. Опрашивает сенсор `"acceleration"` (акселерометр) по осям X, Y, Z. Позволяет освобождаться от захвата зомби путём встряхивания телефона (shake mechanic). |
| **`f`** | Менеджер игровых сущностей и логики персонажа (Actor/Entity Manager) | **HIGH** | Содержит 288 методов, управляющих поведением игрока, патронами, здоровьем, ИИ зомби, их спауном, движением и анимациями (`c[] a`). Проверяет коллизии объектов с физической сеткой карты, считываемой из `g.g`. |
| **`g`** | Главный игровой контроллер, физический движок и Canvas (Core Game Engine) | **HIGH** | Наследует `javax.microedition.lcdui.Canvas` и реализует `java.lang.Runnable`. Содержит главный игровой цикл (`run()`), диспетчер состояний (`switch (a)` в `o()` и `p()`), методы воспроизведения звуков (`javax.microedition.media.Player`), менеджер уровней и загрузки бинарных карт (`m0` — `m13_2`). |
