## 2. Обоснование связей с Java-кодом

*   **Класс `g.java` (Level Loader):**
    *   Считывает `segment_00` для построения слоев отрисовки тайлов пола и стен в методе `g.l(Graphics)`.
    *   Считывает `segment_01` во встроенный одномерный массив коллизий, используемый в `g.g` для блокировки движения.
    *   Считывает `segment_09` для вывода диалогов на экран при переходе в состояние `11` (Story Cutscenes).
*   **Класс `f.java` (Entity Manager):**
    *   Парсит `segment_02` в цикле инициализации актеров уровня `f.a()`. Каждая запись содержит координаты X, Y и тип врага.
*   **Класс `a.java` (Sprite Decoder):**
    *   Создает объекты типа `a` (спрайт-листы) для сегментов `04`, `05`, `06`, `07`, `08` для покадровой отрисовки графики уровня.
