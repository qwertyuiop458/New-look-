# Карта соответствия спрайтов и игровых сущностей (Sprite-Entity Map)

В данном документе описана взаимосвязь между бинарными графическими сегментами `t0`, анимационными контроллерами и высокоуровневыми объектами/сущностями игры.

---

## 1. Схема цепочки связей

```
[Сегмент t0] ──> [Спрайт-лист класс a] ──> [Контроллер класс c] ──> [Менеджер сущностей f] ──> [Игровой объект]
```

---

## 2. Таблица сопоставления сущностей

| Источник (`t0`) | Игровой объект | Класс управления | Метод рендеринга | Описание поведения |
| :---: | :--- | :---: | :--- | :--- |
| **`segment_04.bin`** | **Игрок (Player Character)** | `f`, `c`, `g` | `g.l(Graphics)` | Главный герой игры. Перемещается по осям X/Y, анимируется с помощью `c` (бег, стрельба, перезарядка, получение урона). Имеет привязку к спрайтам оружия из `segment_10.bin`. |
| **`segment_05.bin`** | **Рядовой Зомби (Common Zombie)** | `f`, `c` | `f.g(Graphics)` | Основной враг. Преследует игрока по кратчайшему пути по сетке коллизий. При сближении проигрывает анимацию укуса (запуск триггера тряски акселерометра в `e`). |
| **`segment_07.bin`** | **Мутанты / Зомби-Боссы** | `f`, `c` | `f.g(Graphics)` | Крупные противники с повышенным здоровьем. Обладают специальными видами атак (удары по земле, метание слизи). |
| **`segment_10.bin`** | **Оружие в руках (Weapons)** | `g`, `c` | `g.l(Graphics)` | Спрайты пушек, накладываемые поверх рук игрока в зависимости от активного слота оружия `g.L[1]` (Пистолет, Дробовик, Автомат). |
| **`segment_03.bin`** | **Игровой интерфейс (HUD)** | `g` | `g.l(Graphics)` | Отрисовка полосы здоровья, индикатора патронов, радара и текущих квестовых подсказок в верхней и нижней частях экрана. |
| **`segment_12.bin`** | **Витрина магазина (Shop UI)** | `g` | `g.n(Graphics)` | Иконки улучшений оружия, аптечек и бронежилетов на экране межмиссионных апгрейдов. |
| **`segment_08.bin`** | **Визуальные эффекты (VFX)** | `f`, `c` | `g.l(Graphics)` | Вспышки выстрелов, падающие гильзы, разлетающаяся кровь при попадании в зомби. Временные объекты с автоудалением из пула. |
| **`segment_16.bin`** | **Диалоги (Cutscene Avatars)** | `g` | `g.ao(Graphics)` | Портреты персонажей, выводимые слева и справа от текстового окна диалогов на русском языке. |
