# GAME BIBLE V4 — дополнение к V3 (этап 15.26)

**Дата:** 2026-08-15 · **Изменения от фронтьер-аудита (только доказанные):**

## Новые подтверждённые факты

1. **Метод объекта-миссии в bytecode — `g.aR(f, int, byte[], int)`** (сигнатура `(Lf;I[BI)V`, CP nameandtype 2833). CFR-декомпилятор переименовал в `g.a(f2, n, byArray, n2)` из-за коллизии имён.
2. **5 invokestatic-вызовов aR** в g.class (offsets 100050, 267158, 401764, 401904, 403586) — по одному на каждую из 5 миссий. Цепочка `mission data → L==10 → cB/Q[]/cy` подтверждена структурно.
3. **Save slots:** ровно 2 физические записи RMS подтверждены (B(2), c(1)/c(2), a(1,D)/a(2,E)); логических слотов > 2 не доказано.

## Уточнено

4. Вторичный парсер g.a(byte[]) (1682) — таблицы СЦЕН (19 опкодов 11-44), отделён от 46 mission opcode.
5. m8 seg0/1/2 — NO_STATIC_CONSUMER_FOUND (окончательно).
6. Q[] значения миссий — статически неоднозначны (RUNTIME).

## Не изменено

Все остальные факты V3 остаются без изменений. V4 — patch над V3, не переписывание.
