# МЁРТВАЯ ЧАСТОТА (DEAD FREQUENCY)
## Design Bible нового самостоятельного сиквела — Этап 15

| Поле | Значение |
| :--- | :--- |
| **Название** | «Мёртвая частота» / DEAD FREQUENCY |
| **Жанр** | Изометрический зомби-шутер с выживанием, 3/4 перспектива |
| **Целевая платформа** | Java ME (CLDC-1.0 / MIDP-2.0), J2ME-совместимые телефоны, 240×320 |
| **Эталон (reference only)** | Zombie Infection, Gameloft SA, 2008 — только как референс архитектуры и механик |
| **Статус** | DESIGN PHASE — код не пишется, оригинальные ресурсы не используются |
| **Дата** | 2026-08-14 |
| **Ветка** | `arena/01a001a1-new-look` (от `33f724fc44a08cda55664a89c87d6c0371542f94`) |
| **Файлы этапа** | см. разделы 8–16: JSON/MD-артефакты в `research/sequel/` + `research/scripts/validate_sequel_design.py` |

Все цифры механик (health, speed, damage, тайминги) заданы в формате fixed-point оригинала
(единица = `1 << 14 = 16384`) и укладываются в 16-битные целые — совместимо с CLDC-1.0.

## 2. CORE GAMEPLAY

Базовый цикл миссии (наследует ритм оригинала, но с новой структурой целей):

```
EXPLORATION → COMBAT → OBJECTIVE → EVENT → PROGRESSION → CLIMAX → COMPLETION
```

| Фаза | Что происходит | Где в миссиях | Техническая основа |
| :--- | :--- | :--- | :--- |
| **EXPLORATION** | Исследование района: улицы, здания, тупики, убежища Фарадея | начало каждой миссии | тайловая карта 64×64, 3–8 слоёв, пеленгатор |
| **COMBAT** | Огневой бой hitscan + снаряды; шум привлекает стаи | встречи по маршруту | пул врагов ≤ 24, ИИ-стейтмашины, шумовые события |
| **OBJECTIVE** | Цель миссии: восстановить питание, найти запись, открыть маршрут | средняя часть | квест-флаги, квест-предметы, опкоды |
| **EVENT** | Скриптовое событие: скачок сигнала, запертые двери, погоня «эха» | переломный момент | опкоды 0–13, триггерные зоны |
| **PROGRESSION** | Награда: утиль, оружие, предметы; магазин между миссиями | экран завершения + магазин | состояние «магазин», таблицы апгрейдов |
| **CLIMAX** | Усиленная волна, мини-босс или финальная задача | конец миссии | волновые таблицы, босс-арены |
| **COMPLETION** | Статистика: убийства, точность, время, утиль | экран «миссия пройдена» | экран статистики (как состояние 7) |

Сквозной мета-цикл: **утиль** (валюта) → **магазин** (апгрейды урона/магазина/перезарядки) →
**новое оружие по сюжету** → **доступ к новым районам** → **3 акта** → **финал на вышке**.

Правила оригинала сохранены как база: победа — достижение триггера выхода/цели; поражение —
HP = 0 (экран Game Over, рестарт с чекпоинта). Чекпоинты = убежища Фарадея.

## 3. PLAYER

### 3.1 Identity
**Григорий Сокол**, позывной «ГРОМ», 37 лет, инженер радиорелейной связи, бывший военный
связист. В момент катастрофы нёс смену в экранированном аппаратном бункере вышки «Релей-13»
и потому не пострадал от «сигнала 47». Новый персонаж — не копия полицейского оригинала.

### 3.2 Role
Одиночный выживший-техник: не боец спецназа, а человек, который чинит, отключает и
перенастраивает. Это оправдывает механики override/field repair и финальную цель (перегрузка
передатчика), а не «побег из города».

### 3.3 Movement (baseline: оригинал)
| Параметр | Значение | Примечание |
| :--- | :--- | :--- |
| Скорость | `16384` fixed-point (= 1 px/тик-шаг оригинала) | baseline |
| Диагональ | ×`11585` (0.7071) | baseline |
| Хитбокс | 24×40 px | baseline |
| Ускорение (новое) | +25% на 10 сек (стимулятор) | сдвиговая математика ×5/4 |
| Статический заряд | +30% скорости при заряде 100 | экспериментальная механика |

### 3.4 Health
- Максимум **100 HP** (baseline).
- Уроны: укус 10 (baseline-зомби), когти 12–20, кислота 8 + DoT 4, взрыв 15 AoE, падение 20.
- Лечение: бинт +25, аптечка +50, убежище Фарадея +1 HP/сек (новое).
- Броня (новое, магазин): 3 уровня, поглощение 10/20/30% (целочисленное округление).

### 3.5 Abilities (новые)
| Способность | Тип | Расход | Описание |
| :--- | :--- | :--- | :--- |
| Ручной обвод | активная | нет | Тайминг-мини-игра: двери, щиты, лифты, пульты |
| Глушилка-доза | активная | 1 заряд | 3 сек глобального стаггера «связанных» врагов на экране |
| Полевой ремонт | активная | утиль | Починка оружия, крафт на верстаках |
| Пеленгатор | пассивная | нет | Стрелка на цель (8 направлений, int-математика) |

### 3.6 Interaction
- Двери: открытые / запертые (пропуск) / с обводом / взламываемые выстрелом (ломщик).
- Объекты: рубильники, пульты, вентиляционные решётки, бочки (взрывные), ящики (лут).
- Радиоточки: сюжетные диалоги с доктором Ланской.
- Выжившие: спасение → сопровождение до убежища → награда.
- Предметы: авто-подбор патронов (baseline), аптечка на «0», активные предметы на «#».

### 3.7 Weapon handling
- Слоты 1–7 (циклическое переключение клавишей «1»), огонь — «5», перезарядка — «2».
- 3 калибра + ЭМИ-ячейки + монтировка; патроны раздельные.
- Реализм J2ME: hitscan не требует снарядов; единственный снарядный ствол (гранатомёт)
  использует пул ≤ 8 объектов.

### 3.8 Progression
| Этап | Что даёт |
| :--- | :--- |
| Миссия 1 | Пистолет «Оса-М» + монтировка (стартовый комплект) |
| Акт I (м. 6) | Дробовик «Сплав-12» |
| Акт II (м. 9/10/12/14) | Автомат «Кедр-9», гранатомёт «Кувалда», винтовка «Долгий», ЭМИ «Глушитель» |
| Магазин | Апгрейды: урон ×1.1/1.2/1.3, магазин +20%, перезарядка −15%, броня, расходники |
| Акт III | Заряды статики, глушилка-дозы, финальный утиль |

### 12.1 Мир
**Затонск-9** — закрытый промышленный город (вымышленный, ~200 тыс. жителей), построенный
вокруг научно-производственного комплекса связи. Осень 2009 года. Экспериментальный
передатчик **«Релей-13»** на окраине начал вещание на частоте **47** — «мёртвый эфир»:
сигнал перезаписывает стволовые рефлексы погибших, поднимая их и связывая в стаи,
управляемые ближайшими ретрансляторами. Город запечатан приказом командования; связь
держится только на проводных линиях и в экранированных зонах.

### 12.2 Персонажи (все новые)
| Персонаж | Роль |
| :--- | :--- |
| Григорий Сокол («ГРОМ») | протагонист, инженер связи, бывший военный связист |
| Доктор Вера Ланская | нейробиолог НИИ «Вектор-9», выжила в изоляторе; ведёт героя по проводной сети |
| Подполковник Савченко | комендант карантина; голос в эфире, приказывает «сбросить» город |
| Семён | радист техникума, первый спасённый выживший |
| «Эхо-Прайм» | финальный противник: оператор вышки, слитый с передатчиком |

### 12.3 Сюжетная дуга (новые сцены, без заимствований)
1. **Акт I**: Сокол выходит из бункера в мёртвый город; находит Семёна, выходит на связь
   с Ланской; прорывается через баррикады к трамвайному депо, где уничтожает «Таран» —
   первого ломщика.
2. **Акт II**: по записям Ланской герой понимает природу сигнала; собирает частотный план:
   больница, НИИ, телецентр; переживает первую встречу с «эхом»; через заставу Савченко
   и вокзал эвакуирует выживших к подножию вышки.
3. **Акт III**: подъём по «Релей-13»: караульная, релейный этаж, антенная шахта; в
   аппаратной запускает цепную перегрузку; на крыше уничтожает «Эхо-Прайм»; передатчик
   замолкает. Эпилог: рассвет, тишина в эфире, у бункера собираются выжившие.

### 12.4 Атмосфера и темп
- Атмосфера оригинала (тесные улицы, одиночество, внезапные толпы) сохранена;
- темп: Акт I — частые бои и обучение, Акт II — чередование боёв и загадок-обводов,
  Акт III — вертикальный подъём и эскалация.
- Тональность: техническая драма «последнего дежурного» — без гротеска и юмора,
  с редкими человеческими сценами в убежищах (новые диалоги).
