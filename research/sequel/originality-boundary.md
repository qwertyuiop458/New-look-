# ORIGINALITY BOUNDARY — «МЁРТВАЯ ЧАСТОТА» (DEAD FREQUENCY)

Границы оригинальности для разработки сиквела. Оригинал — Zombie Infection
(Gameloft SA, 2008), исследовательская база в `research/analysis/`.

## 1. Оригинальные материалы — ТОЛЬКО КАК РЕФЕРЕНС (reference only)

Нижеперечисленное используется исключительно для чтения, анализа и измерения.
Ни один фрагмент не переносится в сиквел — ни байт, ни пиксель, ни слово.

- [x] original_code: reference only — исходный Java-код (GloftMASS.java, g.java, f.java,
  c.java, a.java, b.java, e.java и др.) служит только источником знаний об архитектуре;
  код сиквела пишется с нуля по спецификациям design bible.
- [x] original_binary_resources: reference only — бинарные ресурсы (t0, сегменты,
  palettesAmount.bin, файлы уровней m0–m13_2, dataIGP) не копируются и не
  переупаковываются; сиквел использует собственный контейнер и собственные данные.
- [x] original_sprites: reference only — все спрайты, кадры, анимационные листы и палитры
  оригинала не используются; новые ассеты рисуются с нуля в той же сетке (32×48, 16×16).
- [x] original_dialogue: reference only — оригинальные диалоги, реплики, портреты и
  тексты локализации не переносятся; все тексты сиквела написаны заново.

## 2. Новые материалы — СОЗДАНЫ НЕЗАВИСИМО (independently created)

- [x] new_code: independently created — движок, ИИ, скрипты и тулзы пишутся с нуля
  (язык/структура могут повторять J2ME-идиомы, но не код оригинала).
- [x] new_assets: independently created — спрайты, тайлы, палитры, шрифты, звуки
  создаются заново; совпадения с оригиналом не допускаются (проверка визуального сходства).
- [x] new_dialogue: independently created — все диалоги, персонажи, имена и сцены новые.
- [x] new_levels: independently created — карты, миссии, триггеры и скрипты уровней
  проектируются заново; названия оригинальных уровней (m0–m13_2) не используются.

## 3. Правила для команды

1. Не открывать оригинальные ресурсы в редакторе с целью «подправить» — только чтение.
2. Не извлекать спрайты/звуки из JAR в рабочие папки сиквела.
3. Не использовать оригинальные имена персонажей, локаций и сюжетные события.
4. При сомнении в сходстве нового ассета с оригинальным — перерисовать.
5. Исследовательская база (`research/analysis`, `research/decompiled`,
   `research/extracted`) — неизменяемый архив; правки в неё не вносятся.

## 4. Юридическая позиция

Сиквел — самостоятельное произведение, вдохновлённое жанровыми и архитектурными
решениями оригинала, но не содержащее его кода, графики, текстов и названий.
