# Отчёт по подготовке исследовательской среды (Environment Setup Report)

## Версии установленного ПО и инструментов
*   **Python:** `3.11.2` (предустановлен в системе).
*   **Node.js:** `v22.22.3` (предустановлен в системе) с менеджером пакетов `npm` (`10.9.2`).
*   **Java JDK:** `openjdk version "25.0.2" 2026-01-20 LTS` / `Temurin-25.0.2+10`.
    *   *Примечание:* Из-за ограничений песочницы (блокировка прямого HTTPS/SSL-соединения ко многим внешним серверам разработчиков, включая `githubusercontent.com` и `adoptium.net`), JDK был успешно развёрнут через PyPI-пакет `jdk4py` в виртуальном окружении Python. 
    *   *Путь к бинарнику java:* `./venv/bin/python3 -c "import jdk4py; print(jdk4py.JAVA)"`
*   **CFR Decompiler:** Версия `0.152` (WASM-порт для JavaScript/Node.js).
    *   *Примечание:* Был успешно развёрнут NPM-пакет `@run-slicer/cfr`, который содержит WASM-сборку официального декомпилятора CFR. Она работает без сетевых запросов и декомпилирует файлы на лету внутри Node.js.

## Доступные команды
*   `python3 research/scripts/extract_jar.py <путь_к_jar> <директория_вывода>` — Скрипт для воспроизводимой и полной распаковки JAR-архивов.
*   `node research/scripts/decompile_class.js <путь_к_классу> [выходной_файл]` — Скрипт для декомпиляции отдельного `.class` файла с использованием WASM-версии CFR 0.152.
*   `./venv/bin/python3` — Запуск Python-интерпретатора с доступом к JDK (`jdk4py`).
*   `unzip` — Стандартная системная утилита для быстрой распаковки.

## Статус работоспособности инструментов

### Успешно работают:
1.  **Распаковщик JAR (`extract_jar.py`):** Работает идеально на основе встроенного модуля `zipfile` в Python. Полностью воссоздаёт структуру каталогов.
2.  **CFR Java Decompiler (WASM-версия через Node.js):** Работает стабильно. Интегрирован в скрипт `decompile_class.js`, который автоматически подгружает зависимости классов из директории распакованного JAR при анализе связей.
3.  **Виртуальное окружение Python & `jdk4py`:** Успешно развёрнуто, предоставляет полноценную Java 25 Runtime.

### Временно недоступны или ограничены:
1.  **Стандартные системные пакеты `openjdk` (через apt-get):** Недоступны из-за сетевой изоляции репозиториев Debian. *(Полностью компенсировано локальным `jdk4py`)*.
2.  **Прямая загрузка CFR `.jar` из GitHub Releases:** Заблокирована фаерволом на уровне домена `objects.githubusercontent.com`. *(Полностью компенсировано WASM-портом `@run-slicer/cfr` на Node.js)*.
