## 5. Новые установленные факты

- Загрузчик миссии: `g.Z(int)` (g.java:13796): m9 → seg0 (таблица длин [1,1,1,1,1]) → миссия = seg10+C(n) → маркеры 99 → m8 seg.sub (границы из g.c()).
- Формат записи уровня: `[type u8][id u16][x u16][y u16][len u8][len×u16]`.
- Спец-записи: 101 = тайловая ячейка (tile_id, y, значение, проходимость), 102 = объект, 103 = данные, 110..172 = скрипты.
- 5 миссий (m9 seg10..14), а не «30 уровней».
- m12 = sin-таблица (181×u16); m7/m6_* = спрайт-пакеты.
